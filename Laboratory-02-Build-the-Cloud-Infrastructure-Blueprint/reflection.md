# Mission Reflection

During this laboratory activity, I learned more about the basic components and concepts of cloud computing. For me, the most important cloud infrastructure component is compute resources because they provide the CPU and memory needed to run applications, process data, and perform different tasks. Without enough computing power, a cloud server cannot properly run the services and applications needed by users. However, I also learned that compute resources need storage, networking, and an operating system to work properly. All of these components are important because they work together to create a complete cloud environment. Linux also plays an important role in cloud computing because it provides a stable environment for running servers, applications, and cloud services. During the activity, I used the KillerCoda Linux environment and Ubuntu to check the operating system, kernel version, CPU, memory, storage, hostname, and IP address. By using Linux commands such as `uname -r`, `free -h`, `df -h`, and `hostname`, I was able to investigate the resources available on the cloud server. This helped me understand how Linux is used to manage and monitor cloud infrastructure. I also learned why technical documentation is important before deploying infrastructure. Documentation helps organize information about the resources, configuration, and purpose of the infrastructure. It can help prevent mistakes because the people working on the project can clearly understand what needs to be set up. It is also useful for troubleshooting, maintenance, and future updates.

During this laboratory activity, I learned new skills such as using basic Linux commands, checking system information, identifying compute, storage, and networking resources, and understanding the role of an operating system in cloud computing. I also learned how to compare the services of AWS, Microsoft Azure, and Google Cloud Platform, create a simple cloud infrastructure diagram, and write technical documentation using Markdown. After completing this mission, my GitHub portfolio improved because I was able to add organized laboratory files, reports, documentation, and a cloud infrastructure diagram. It now shows the activities and skills I learned during the laboratory, especially my basic knowledge of Linux, cloud infrastructure, Markdown documentation, and cloud computing concepts.
