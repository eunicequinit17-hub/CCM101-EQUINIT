# Checkpoint 4 – Research the Major Cloud Providers

## Cloud Provider Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| **Compute** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Storage** | Amazon S3 | Azure Blob Storage | Cloud Storage |
| **Networking** | Amazon VPC | Azure Virtual Network (VNet) | Virtual Private Cloud (VPC) |
| **Identity and Access Management (IAM)** | AWS Identity and Access Management (IAM) | Microsoft Entra ID | Google Cloud IAM |

## 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest ranges of cloud services among the three providers. It provides a large number of services for compute, storage, networking, databases, security, AI, analytics, and many other areas, giving organizations many options for building cloud solutions.

## 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure for an organization that primarily uses Microsoft products. Azure works well with Microsoft services and technologies, making it easier for organizations already using Windows, Microsoft 365, Active Directory, and other Microsoft products to connect their systems to the cloud.

## 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is widely recognized for its strong services in Artificial Intelligence, Machine Learning, and Kubernetes. Google developed Kubernetes and provides Google Kubernetes Engine (GKE), while also offering different AI and ML tools for developing and running intelligent applications.

## 4. What similarities did you observe among the three cloud providers?

All three cloud providers offer similar core infrastructure services, including compute, storage, networking, and identity and access management. They allow users to create and manage cloud resources without having to own and maintain physical servers, and they provide services that can scale depending on the needs of an organization.
