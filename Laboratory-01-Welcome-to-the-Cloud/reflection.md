## Reflection

This activity gave me my first experience using a cloud-based Linux environment through KillerCoda. I learned how to access an Ubuntu playground, use the terminal, and run basic Linux commands to check information about the system.

I also learned how to create a new Linux user account with a home directory, Bash shell, and `sudo` access. Logging in to the new account helped me understand how users and permissions work in Linux.

One important thing I learned from this activity is that I need to be careful when using Linux commands because each command has a specific purpose. Using commands like `whoami`, `pwd`, and `hostname` helped me check important details about the system. This activity also helped me become more comfortable using the Linux terminal and gave me a better understanding of the basics of cloud computing.
