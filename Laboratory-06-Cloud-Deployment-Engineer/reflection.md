# Mission Reflection

This laboratory helped me understand how Docker Compose can make cloud deployment easier and more organized. Instead of entering many Docker commands one by one, I can put the required settings in a `docker-compose.yml` file. After creating the file, Docker Compose can start the needed services with just one command. This makes the process simpler and easier to repeat.

I also learned that YAML needs proper indentation. Spaces are important because they show how the different parts of the configuration are connected. If I use a Tab or put the spaces in the wrong place, Docker Compose may not be able to read the file and an error can occur. Because of this, I learned that I need to be careful when writing and checking a YAML file.

Another thing I learned was the use of environment variables such as `MYSQL_PASSWORD`, `MYSQL_DATABASE`, and `MYSQL_USER`. These variables provide important settings for the containers and help them connect and work properly. They also make it easier to change the settings without changing the main application configuration.

Deploying Nextcloud within a few minutes was a good experience for me. I was able to see how the application, database, and containers work together. When I saw the Nextcloud setup page in the browser, I felt that the deployment was more practical because I could actually see the result of the commands I used.

My understanding of Cloud Computing has also changed since Mission 1. Before, I mostly thought of cloud computing as using computer resources through the internet. Now, I have learned more about containers, storage, databases, networking, infrastructure, and deployment. This laboratory helped me realize that cloud computing also requires different services to be properly configured and connected so they can work together as one system.
