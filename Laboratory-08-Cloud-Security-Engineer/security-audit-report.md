# Security Audit Report

## Checkpoint 2 - Security Best Practices

### 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users only the permissions and access they need to perform their tasks. It is important for cloud user accounts because it helps prevent unauthorized access and reduces the possible damage if an account is compromised.

### 2. Attack Surface

An attack surface refers to all the possible points where an attacker could try to access or attack a virtual machine. This can include open network ports, running services, applications, and other exposed components.

### 3. Default Deny Policy

A Default Deny Policy means blocking incoming traffic by default and only allowing the specific connections that are needed. This is safer because unknown or unwanted traffic is automatically blocked instead of trying to identify and block every individual attacker.
