# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory activity is about using MinIO for cloud object storage. The main goal is to create a simple storage environment for a photo-sharing application that needs a reliable place to store many user-uploaded images.

## Objectives

* Learn about the different types of cloud storage.
* Understand the differences between Block Storage, File Storage, and Object Storage.
* Set up MinIO through Docker.
* Access and manage MinIO using its Web Console.
* Create a storage bucket called `client-photos`.
* Upload a sample file to the created bucket.
* Record and document the steps used during the deployment.

## Tools Used

* KillerCoda Ubuntu Playground
* Docker
* MinIO
* MinIO Web Console
* Linux Terminal
* Git and GitHub
* Markdown

## Skills Learned

* Learning how different cloud storage types are used
* Setting up a cloud storage server with Docker
* Managing and checking Docker containers
* Navigating the MinIO Web Console
* Creating and organizing object storage buckets
* Uploading files as objects to cloud storage
* Using basic Linux terminal commands
* Creating technical documentation for cloud infrastructure
