# Google Cloud Platform (GCP)

## Brief Overview

Google Cloud Platform (GCP), also known as Google Cloud, is a cloud computing platform provided by Google. It offers services for computing, storage, networking, databases, containers, data analytics, and artificial intelligence.

## Global Infrastructure

Google Cloud uses a global infrastructure consisting of regions and zones. Google Cloud currently lists 43 global regions and 130 zones. Its infrastructure is designed to support high performance, availability, and global workloads.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources and services. Users can create virtual machines, manage storage, configure networks, deploy Kubernetes workloads, and monitor cloud resources.

## Four Core Services

1. **Compute Engine** – Provides virtual machines for running applications.
2. **Cloud Storage** – Provides object storage for data and files.
3. **Virtual Private Cloud (VPC)** – Provides networking for cloud resources.
4. **Cloud IAM** – Manages identities, roles, and permissions.

## Three Advantages

1. Google Cloud provides strong artificial intelligence and machine learning capabilities.
2. It provides strong support for Kubernetes and containerized applications.
3. Its global infrastructure supports applications deployed across multiple regions and zones.

## Typical Enterprise Use Cases

Google Cloud is commonly used for artificial intelligence, machine learning, data analytics, Kubernetes applications, web applications, databases, and large-scale data processing.
