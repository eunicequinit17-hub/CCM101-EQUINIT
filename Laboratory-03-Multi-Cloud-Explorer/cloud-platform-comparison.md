## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS is a strong choice for the broadest range of cloud services. It provides services covering computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It works well with Windows Server, Microsoft 365, Active Directory environments, and other Microsoft enterprise technologies.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for artificial intelligence, machine learning, and Kubernetes workloads. Google developed Kubernetes and provides Google Kubernetes Engine (GKE), while also offering many AI and data services.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides many different cloud services and gives users many options for building applications. It is also useful for learning different cloud technologies because of its large service ecosystem.
