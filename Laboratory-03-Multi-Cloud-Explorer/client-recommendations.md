# Cloud Platform Recommendations

## Client A – Startup Company

### Recommended Platform: AWS

AWS is recommended because the startup has a limited budget but expects rapid growth. AWS provides scalable services that allow the company to start with smaller resources and increase capacity as the application grows. The startup can also choose managed services to reduce infrastructure management. Useful services include **Amazon EC2, Amazon S3, and Amazon RDS**.

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is recommended because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft technologies and supports hybrid cloud environments. This can make migration and identity management easier for the university. Useful services include **Azure Virtual Machines, Microsoft Entra ID, and Azure Blob Storage**.

## Client C – AI Research Company

### Recommended Platform: Google Cloud

Google Cloud is recommended for the AI research company because it provides strong artificial intelligence, machine learning, data, and high-performance computing capabilities. The company can use cloud infrastructure to run demanding workloads without maintaining all physical hardware. Useful services include **Compute Engine, Google Kubernetes Engine, and Vertex AI**.

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is recommended because the company operates globally and requires high availability and automatic scaling. AWS provides infrastructure distributed across regions and Availability Zones, allowing applications to be designed for resilience and global availability. Useful services include **Amazon EC2, Elastic Load Balancing, and Amazon RDS**.

## Multi-Cloud Decision Matrix

| Business Requirement    | Recommended Platform | Justification                                         |
| ----------------------- | -------------------- | ----------------------------------------------------- |
| Startup Company         | AWS                  | Wide service selection and scalable infrastructure    |
| Enterprise Organization | AWS                  | Broad enterprise services and global infrastructure   |
| Microsoft Environment   | Azure                | Strong Microsoft integration                          |
| AI / Machine Learning   | Google Cloud         | Strong AI and ML capabilities                         |
| Kubernetes Deployment   | Google Cloud         | Strong Kubernetes ecosystem through GKE               |
| Global Web Application  | AWS                  | Global infrastructure, scaling, and high availability |
