# Microsoft Azure

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides services for computing, storage, networking, databases, artificial intelligence, security, and enterprise applications.

## Global Infrastructure

Azure provides cloud infrastructure in many geographic locations around the world. Organizations can select suitable regions when deploying their applications and services. This allows businesses to consider performance, availability, and data location requirements.

## Cloud Management Console

The Azure Portal is a web-based management console used to create, configure, monitor, and manage Azure resources. Administrators can manage virtual machines, storage, networking, databases, identities, and other services through the portal.

## Four Core Services

1. **Azure Virtual Machines** – Provides virtual servers for applications and workloads.
2. **Azure Blob Storage** – Provides object storage for unstructured data.
3. **Azure Virtual Network** – Provides private networking for Azure resources.
4. **Microsoft Entra ID** – Provides identity and access management.

## Three Advantages

1. Azure provides strong integration with Microsoft products and technologies.
2. It supports hybrid cloud environments.
3. It provides many enterprise-focused cloud services and security features.

## Typical Enterprise Use Cases

Azure is commonly used by enterprises for Windows Server workloads, Microsoft 365 integration, databases, business applications, hybrid cloud environments, analytics, and artificial intelligence.
