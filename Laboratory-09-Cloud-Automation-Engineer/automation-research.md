
# Automation Research

## 1. Bash Script

A Bash script is a file that contains Linux commands that can run together automatically. The `#!/bin/bash` line is called the shebang, and it tells the system to use Bash to execute the script.

## 2. Variables

Variables store information, such as folder paths, that a script can use whenever needed. For example, `$BACKUP_DIR` stores the backup folder name, making the script easier to update without changing the same path in many places.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs automatically at a specified time or date. It is useful in cloud operations because it can perform repetitive tasks, such as backups, without requiring someone to run the commands manually.
