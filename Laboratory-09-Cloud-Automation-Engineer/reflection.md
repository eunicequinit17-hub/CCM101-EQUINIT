
# Mission Reflection

Completing the Cloud Automation Engineer mission helped me understand why automation is important in cloud computing. When an organization manages hundreds of servers, performing the same task manually takes too much time and increases the chance of human error. Automation allows administrators to run repetitive tasks consistently, such as creating backups, checking system conditions, and maintaining services. It also helps teams manage larger environments more efficiently.

However, automation can also be dangerous if it is not tested properly. A destructive mistake in a script scheduled to run on 1,000 servers could affect many systems at the same time. For example, an incorrect command might delete important files or overwrite useful data. This is why scripts should be reviewed, tested in a safe environment, and given only the permissions they need. Backup and recovery procedures are also important.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. Bash uses commands, variables, and instructions to perform tasks step by step. Docker Compose YAML describes the services and configuration needed to run containers. Both tools help automate work, but they solve different problems.

Reviewing my GitHub portfolio from Laboratory 1 to Laboratory 9 shows how my understanding of cloud computing has developed. I started by learning basic cloud concepts and infrastructure, then explored containers, data services, deployment, monitoring, security, and automation. These activities helped me understand that cloud computing involves more than simply running applications; it also requires reliable operations and careful management.

The role I enjoyed most was the Cloud Automation Engineer because scripting reduces repetitive manual work and makes tasks easier to repeat. I also found the Security Engineer role valuable because protecting systems is essential. Overall, these missions helped me build practical skills and understand the importance of testing, documentation, security, and continuous learning in cloud operations.
